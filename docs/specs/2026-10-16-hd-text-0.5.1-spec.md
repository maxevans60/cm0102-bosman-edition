# HD text, release 0.5.1
Status: Ready

## Problem
In HD mode the text keeps its pixel size while the screens grow. On a MacBook window about 1,800 pixels wide, HD text is 0.67 of its size in widescreen, and on a 1080p or 4K screen it is 0.74. The side bar, the popup areas and the small notes are hard to read. On a Retina MacBook the HD frame is also scaled below 1x, so thin strokes can drop out with Sharp picture on.

## Solution
HD draws its text 1.35 times bigger by default, so lists keep about as many rows as in widescreen. A new option, HD text, switches between Large and Small. The Traditional fonts get bigger too. When the HD frame is shown smaller than its own size, the picture is smoothed. Widescreen and classic do not change.

## User stories
1. As a player on a MacBook in HD, I want text I can read without leaning in.
2. As a player on a 1080p or 4K screen, I want HD text at about the size of widescreen text, so that HD gives more room, not smaller words.
3. As a player who likes more rows, I want to switch HD text back to Small.
4. As a player who uses the Traditional fonts on Game Settings, I want them bigger in HD as well.
5. As a player on a Retina MacBook, I want no broken letters when the HD picture is shown smaller than 1920x1080.
6. As a widescreen or classic player, I want nothing to change.

## Decisions
- **Approach (Q223):** the game draws its text with its own scalable font engine (font mode -2, the default "Futuristic" fonts). HD multiplies the engine's text sizes, baselines, cursor heights and line heights. The values are 59 constants in the line draw, the text width, the text height and the text box functions (research list). They become a run-time value through the existing patch table of the recompiler.
- **Factor (Q224):** 1.35, the height ratio of HD to widescreen. Sizes 9, 10, 14, 16, 18, 20 and 22 become 12, 14, 19, 22, 24, 27 and 30, with baselines and line heights scaled to match.
- **Option (Q225):** `hd_text = large | small`, default `large`, on the Screen tab of Bosman Edition Options next to Display mode, with the note "Applies at the next start". It acts only in HD.
- **Same game (Q225, Q152):** large and small text give different later days, as two display modes do. The same clicks with the same setting give the same game.
- **Widescreen and classic (Q226):** no change.
- **Smooth picture below 1x (Q227):** when the HD frame is drawn smaller than 1920x1080, the picture uses linear filtering, whatever Sharp picture says. Above 1x, Sharp picture keeps its meaning.
- **Traditional fonts (Q229, Q230):** the bitmap fonts get the same 1.35 factor in HD Large, with smooth scaling of each glyph. Their line heights grow to match.
- **Release (Q228):** 0.5.1, before the 0.6.0 build.
- **Found in the build (2026-10-16), for Max to accept:** in HD Large the attribute groups switch changes the five memory-layout parts of a save when a profile opens, as it does in classic (Q152, Q153), because the 13 rows are lower than the bigger text rows. The Premier Division table shows 8 rows before it scrolls, so the HD Large tests open Chelsea in place of Liverpool. The Team views lists keep their rows of 17 pixels: tight, but no text overlaps. The options box rows are 33 pixels apart in every mode (35 before), so that the Screen tab holds ten rows.

## Testing
- **Same-save seam:** `--same-save` from `start.sav` in HD with `hd_text = large`, twice: equal saves. Widescreen and classic: equal to 0.5.0. HD with `hd_text = small`: equal to 0.5.0 HD.
- **Screen seam:** smoke pictures in HD Large of the squad screen, the profile, Bosman Edition Options (both tabs), Game Settings, the side bar popup area and the match screen. No cut or overlapping text. The squad list shows at least 9 rows per column.
- **Reference pictures:** the HD smoke steps and the HD reference pictures are recorded again for Large (click positions on popup items move). The old pictures stay as Small.
- **Options seam:** `ctest -R options` for the new line.

## Out of scope
- Bigger text in widescreen or classic.
- A free text size slider.
- New fonts.

None.
