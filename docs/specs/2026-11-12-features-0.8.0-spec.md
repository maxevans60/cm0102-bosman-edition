# Features, release 0.8.0
Status: Ready

## Problem
Players ask for the same things again and again: a faster game, the attribute colours they know, switches for rules they do not like (unprotected contracts, foreign player limits), money that keeps up with the years, and a quicker way through a match day. Some of these change how the game plays, and players disagree about them. Today every option sits in settings.txt or in two full tabs of the Options box, and there is no place for options that change the game.

## Solution
Release 0.8.0 makes the game faster at a new game and on each game day, adds a Rules tab with rule options that are off by default, adds inflation, a quick result for a match day and a Faster commentary step, gives attribute colours a Classic scheme, marks your three best players, fixes the first season's ticket money, and hunts the last known crash sites of the original. It also takes the small screen fixes of the old 0.8.0 and 0.9.0 lists. Android and iPhone move to 0.9.0.

## User stories
1. As a player with every nation loaded, I want a new game to start faster, so that I wait less before I play.
2. As a player, I want Continue and holidays to go faster, so that a season takes less time.
3. As a player, I want a Quick result button on match day, so that I can skip the commentary of a match I do not want to watch.
4. As a player, I want a commentary step between Very Fast and Fastest, so that I can follow a match at a pace that suits me.
5. As a long-time player, I want the Classic attribute colours (dark red for 20 down to grey for 1), so that the screens look as I remember.
6. As a player, I want to turn attribute colours off or pick Bosman or Classic in the Options box.
7. As a player, I want a star on my three best players in the squad list, so that I see my key players at a glance.
8. As a player who dislikes unprotected contracts, I want a rule option that stops any contract from becoming unprotected, for every club.
9. As a player, I want a rule option with no foreign player limits in any nation or European cup, while work permits stay as they are.
10. As a player, I want a rule option that keeps private AI bids private, so that AI clubs can sign players on my shortlist without news to me.
11. As a manager who wants to work abroad, I want a rule option that makes clubs in other nations more willing to offer me a job.
12. As a new manager, I want a rule option where my potential starts low and grows as I play and win.
13. As a player, I want a rule option to apply to any club in a league the game loaded, also a background league, but not a club of a nation that was not loaded.
14. As a player with few nations chosen, I want a rule option that loads every player of the database.
15. As a player of long games, I want a rule option with regen fixes: regens only to clubs under 45 players, older regens not to small nations, and no ever-growing Positioning.
16. As a player, I want a rule option that fixes the original's creativity and marking faults in the match engine.
17. As a player, I want a rule option for inflation, so that wages, fees and club income grow each July, and a game that starts in 2026/27 starts with 2026 money.
18. As a player, I want season ticket money in the first season, as in every other season.
19. As a player, I want every rule option set when I start a game and fixed for the whole game, so that one save keeps one set of rules.
20. As a player, I want every option in the game, so that I never need to edit settings.txt.
21. As a player, I want a reloaded match to stay unpredictable, as the original is: reload and replay can give another result.
22. Awkward case: a player turns a rule option on in the Options box during a game. The row shows greyed out and the game keeps the rule it started with. The new value is the default for the next new game.
23. Awkward case: a player takes a job at a club in a background league with "manage any team". The club's league must run so that the club plays its matches.
24. Awkward case: "load every player" on a machine with little memory. New game time and save size are measured and stated in the changelog.
25. Awkward case: inflation on and a start in 2026/27. The season's database already holds 2026 wages and values. Only the sums the game itself keeps at 2001 levels get the 2026 factor, never the data a second time.

## Decisions
Settled in the interview of 12 November 2026 (Q1 to Q26).

### Rules tab and rule options
- The Options box gets a third tab, the Rules tab, beside Graphics and Game. Each rule option has one row.
- Setup Game gets a Rules button that opens the Rules tab for that new game.
- A rule option is off by default, is set for each new game and is stored with the game in the save, as changing rules is. It stays fixed for the whole game. In a running game its row shows greyed out.
- Every option of the game, old and new, has a row in the Options box. None lives in settings.txt only.
- Rule options of this release: unprotected contracts off (107), no foreign player limits (73), hide private bids (124), easier jobs abroad (125), manager potential grows (126), manage any team (127), load every player (128), regen fixes (129), creativity and marking fixes (130), inflation (65).
- No foreign player limits removes the squad, match-day and non-EU limits in every nation and in the European cups. Work permits stay (issue 85).
- Unprotected contracts off applies to every club, AI and human.
- Manage any team covers clubs in every league the game loaded, background leagues included, not clubs of nations that were not loaded.
- Regen fixes and the engine fixes are our own code from the original's code. Each fix cites the address of the original function it changes.

### Inflation (65)
- A yearly growth table by season from public sources, with separate rates for wages, transfer fees and club income. It covers player values and asking prices, wage demands, board budgets, gate receipts, TV and prize money, sponsorship and fixed sums such as fines. Club income rises with wages.
- The start level of a later season applies only when the option is on. With it off, the game plays as before.
- A later season's database already holds that season's wages and values. The start factor applies only to the sums the game keeps at 2001 levels.
- Research comes first, in its own slice, because it is the largest piece.

### Speed (76)
- Two parts: new game start and day processing (Continue and holidays).
- Speed changes may change results. The game was never predetermined.
- Normal play stays random as now: reload and replay can give another result. With a fixed test seed, one build gives the same results each time.
- Order: one fixed benchmark first, then fixes on one thread (file buffers, the shortlist sort, the date helpers), then work that does not depend on other work on more processor cores (background league matches, loading nations at a new game), each task with its own fixed random seed.
- The transfer market stays on one thread.
- Each step ships its gain. The work stops when a step gains less than 5%.
- The market on fewer days stays a test aid only. It is not a game option.

### Match day (80, 81)
- Quick result: a button on match day. The match engine plays the whole match with no commentary, and the result counts as a normal match.
- Commentary speed gets one new step, Faster, between Very Fast and Fastest.

### Display
- Attribute colours has three values: Off, Bosman (today's scheme) and Classic (dark red for 20 down to grey for 1). No custom colours.
- Star players: a star on the three best players by the best XI rating, which uses only the attributes your manager can see. On by default, display only.

### Fixes
- First-season ticket money is a bug fix with no option, in every game, the base game included. The same-save check records the change in club money from the first July as planned.
- The crash hunt gets one slice. Sites: virtual_staff.cpp error 195, transfer_manager.cpp with no player record, the Dutch top league function that returns 0, the Argentine leagues and the Argentine Second Division average points on 1 August, match engine error 1225. Each is fixed at its cause or noted as unreachable in the port. No guards.

## Testing
- **Same-save seam:** `tests/smoke/smoke_run.py --same-save`, with `--match` for match changes. With each new option off, saves stay equal. Display options follow the existing screen-memory rule. Planned differences (first-season tickets) are recorded as named runs and parts, as the Q48 history fix is.
- **Effect seam:** a smoke run with each rule option on that proves its effect in the save, for example no unprotected contract after a season, a squad over a foreign limit that plays, a regen pool with no club over 45 players.
- **Screen seam:** smoke screenshots of the Options box (all three tabs), Setup Game, the squad list and a profile, in classic and widescreen.
- **Code tests:** `ctest` for the options file with the new rows and for the rule options field of the save.
- **Speed seam:** a new fixed benchmark: an all-nations 2001/02 new game, and one month of holiday on a fixed full-world save. Mac before and after each change, one spot check on Windows and Linux. Each speed slice records its new expected results and runs one long test game through a World Cup, a Euros and every season change between.
- **Money seam (65):** long test games from 2001 to 2027 with inflation on, checking that clubs neither go broke nor pile up cash.
- Similar tests: the 0.5.0 options and same-save runs, `same_save_views.py`, the run set.

## Out of scope
- Competition structure changes of any kind (leagues, cups, subs per competition, tournament data).
- One-off patches for single leagues or single rules beyond the rule options above.
- The transfer market on more than one thread.
- The transfer market on fewer days as a game option.
- Custom attribute colours.
- Work permit and attribute cap options (85), in-match attributes (95): after 1.0.
- Android and iPhone: 0.9.0.
