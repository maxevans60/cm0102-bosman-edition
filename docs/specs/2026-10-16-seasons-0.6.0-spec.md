## Problem
The game always starts in July 2001. Players who want a later season must find an Update Team database, install it by hand and patch the original's start year with outside tools. Even then, the game plays every season with the rules and league structures of 2001/02: the Intertoto Cup runs for ever, Serie A has 18 clubs, three substitutes are the limit and no Conference League or Nations League exists. A game that runs on for ten years never changes.

## Solution
A Choose Season screen on the start screen offers every season from 2001/02 to 2025/26 as a tile. The tile chooses the season and its database, and every season's database is in the download. Each season plays with its real rules and league structures, for every league and competition in the game. As a game moves on, each rule changes in the July it changed in real life, until 2025/26 and the changes already announced after it. A news item tells the player what changed. An option turns the changes off for a game. The 2001/02 tile with the option off is the base game, the same game as today.

## User stories
1. As a player, I want to pick any season from 2001/02 to 2025/26 on one screen, so that I can start with the squads of the year I like.
2. As a player, I want the tile to choose the database for me, so that I never install or match a database by hand.
3. As a player, I want the season to start in July of its year, so that I start before the first match.
4. As a player, I want every league in the game to have the club count, promotion places, play-offs and cup formats of that season, so that nobody can tell me the Swedish second division had another size that year.
5. As a player, I want the European cups to have their real format of that season: the Intertoto Cup until 2008, the UEFA Cup with groups, the Europa League from 2009, the Conference League from 2021 and the league phase from 2024.
6. As a player, I want the substitutes, bench size, foreign player rules, work permits and transfer windows of that season.
7. As a player, I want competitions to carry their name of that season, such as the Championship or the Europa League.
8. As a player in a long game, I want the rules to change in the July they changed in real life, so that my game moves with the years.
9. As a player who starts in 2001/02, I want the changes too, unless I turn them off.
10. As a player who wants the original, I want the base game: 2001/02 with the 3.9.68 data and the changes off, the same game as before.
11. As a player who reaches a new rule, I want a news item that says what changed, so that I do not think a missing cup is a fault.
12. As a player past 2025/26, I want the changes already announced with a date to come in, and the rules then to stay.
13. As a player with a save from 0.5.0 or earlier, such as Max's Yeovil save, I want it to load and play exactly as before.
14. As a player, I want new international competitions, the Nations League and the 48-team World Cup among them, from the year they started.
15. As a player who picks 2004/05 or 2006/07, I want to see that no database exists for that season, so that I do not think the screen is broken.
16. As a player who wants another version of a season, such as an April or SIM database, I want a link to the Update Team's downloads page and a version choice once I add it.
17. As a player with my own database folder, I want a Custom database tile where I name its season, so that my data still works.
18. As a player, I want the tile colours to tell me the era, so that I know which European format a season has.
19. As a player with little disk space, I want only the seasons I use to take space on disk.

## Decisions

### Release
- **One release (Q231):** 0.6.0 holds all of #50 to #53. No split. It ships only when every league and competition of the game is researched and checked for every season. No date is set.
- **Every league (Q242):** the scope is every league and competition that the original runs: all divisions and domestic cups of the 27 nations of the league table, the continental club competitions and the international competitions. Leagues added by outside patches are out. Leagues of nations that a game cannot select stay out. The new competitions of #53 come in because Q169 asks for them.
- **Accuracy (Q243):** a rules table with one row per league or competition per season. A row holds the club count, the promotion, relegation and play-off places, splits, the cup format, substitutes and bench, foreign player and work permit rules, squad registration, transfer windows and the name. Each fact carries the URL of a page read on the day. A second Opus agent checks every row against a second source. Rows where the sources disagree go to Max.
- **No outside names:** no committed file, issue or message names another modder, their patch or their tool (handover rule). Outside patch sources are research maps only. No code is copied.

- **ODB and SIM (Q253, Q256):** SIM style keeps attributes close to real life. ODB style keeps them high, as the original does. The rule of Q263 decides, and quality comes first. SIM databases are extras.
- **No database (Q234):** 2004/05 and 2006/07 show a greyed tile with "No database yet". The Update Team's Databases forum has 49 topics, the same 49 we hold, and none for these seasons.
- **Official tiles (Q233):** the 2001/02 tile starts July 2001 with the 3.9.68 data by default and offers 3.9.60 and 3.9.65 as versions. The 2002/03 tile starts July 2002 with the 3.9.68 data.
- **Start date (Q146):** July of the chosen season.
- **Download (Q235, Q250, Q251):** the download holds the three official data sets and the 21 season databases. Each season database stays zipped (about 300 MB together) and unpacks into the save folder the first time a player picks that season (about 1.4 GB if all are unpacked).
- **Extra databases (Q252, Q257, Q264):** "More versions" is gone. The screen links to the Update Team's downloads page at champman0102.co.uk. A player who adds an Update Team database to the `Databases` folder sees a version choice on that season's tile. Max confirmed (2026-10-16): the game recognises the 49 known Update Team databases by their content, so a folder name does not matter.
- **Custom database (Q254):** a folder that is not a known Update Team database gets a Custom database tile after the seasons. The player picks the folder and names its season, and that season's rules apply.
- **Credit (Q147, Q269):** the screen and the site credit the maker of each database: the Update Team, or the person named in the forum topic (October 2003 and September 2005).

### Season rules
- **Eras (Q166, Q240, Q261):** five eras: Original 2001/02 to 2002/03 (red), 2000s 2003/04 to 2008/09 (amber), 2010s 2009/10 to 2019/20 (green), early 2020s 2020/21 to 2023/24 (blue), league phase 2024/25 on (purple). The tile headings follow the eras. Within an era, the rules table gives the exact rules of each season.
- **Changing rules (Q232, Q245):** a new option `changing_rules`, set for each game in Setup Game and kept in the save. The settings file holds the default for a new game, and the default is on. A game cannot change it after the start. With it on, the season rules change each July, for every start season including 2001/02 and 2002/03. With it off, the rules of the start season stay for the whole game. This replaces the part of Q165 that kept the official seasons unchanged.
- **Where it shows (Q259):** Setup Game shows the switch for the new game. The Options screen's Game tab shows the default.
- **Old saves (Q246):** saves from 0.5.0 and earlier load with `changing_rules` off and play exactly as before.
- **Promotion during a game (Q247):** the game's own results decide which clubs go up and down. The real numbers of each season apply, so a transition season uses its real promotion and relegation counts. Real club names apply only at the start of a new game.
- **Club moves at a new game (Q225, Q237):** a table for each season puts every club of a resized or new division into its real division of that season, in memory. The database files stay unchanged.
- **Missing clubs (Q244):** when a real division has more clubs than the database puts in it, the club moves take that nation's clubs that have no division in the database. If none exist, the research lists the case for Max. No club records are added without his decision.
- **Names (Q226, Q238):** competitions get their name of each season in memory when a game loads, from our own names table. The database files stay unchanged.
- **First-season branches (Q170, Q239):** the original's 2001 special cases move with the start year. Where the rules table disagrees with a moved branch, the rules table wins (for example Ligue 1 has 20 clubs in 2010/11).
- **After 2025/26 (Q248):** changes already announced with a date apply when the game reaches them, for example 6-club Championship play-offs from 2026/27 and the Africa Cup of Nations every four years from 2028. The rules then stay.
- **Out (Q249):** VAR, goal-line technology, financial fair play and profit rules, and FIFA loan limits. The winter break and concussion substitutes come in only if the research shows that the fixture and substitute code can hold them without a change to the match engine.
- **News (Q258):** at the start of each season in which the rules change, the player gets one news item that lists the changes.
- **New competitions (Q169):** the competitions that the original has no code for get new code, among them the Nations League, Euro qualifying with Nations League paths and the 48-team World Cup with its qualifiers.
- **Same game rule (Q152, Q241, Q342):** the base game gives a save byte for byte the same as 0.5.0 with the same clicks, up to slice 13; from slice 13 the 0.6.0 base game is the reference and a test switch that turns the season code off must give the same save. Other seasons have no original to compare against: the same clicks give the same save twice.

## Testing
- **Rules report (Q265), the main seam:** a start flag of the test program starts a new game in a season, then jumps from season to season with no days played, running the end-of-season step for each year up to a named year. If that step needs match results, the flag fills in quick results first. At each season it writes the competitions, club counts, names and rules that the game holds to a text file. A test compares that file with the rules table. This checks behaviour the player sees (which competitions run, with how many clubs, under which rules), not internals.
- **Database load:** each season database loads and reaches the first news screen, as in `tests/smoke/update_team_sweep.py` (about 75 seconds each, run in parallel). No full-season runs (Q260).
- **Base game and old saves:** `tests/smoke/smoke_run.py --same-save` on `start.sav` and `prematch.sav` with the base game gives the same save as 0.5.0. Max's Yeovil save loads, plays one week and gives the same save as 0.5.0.
- **Repeatability:** for each new season, the same clicks give the same save twice.
- Existing tests to build on: `update_team_sweep.py`, `custom_database_run.py`, `database_order_run.py`, `smoke_run.py`.
